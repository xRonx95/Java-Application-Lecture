Topic 02

Tools and requirements

NetBeans is the development environment, while the JDK supplies the compiler and Java runtime tools. Both are needed to create and run the project.

JDK

Java Development Kit

Contains javac, the Java compiler, and the tools required to build Java applications.

IDE

Apache NetBeans

Provides the editor, project manager, GUI Builder, debugger, and output window in one application.

SW

Java Swing

A built-in Java toolkit containing JFrame, JButton, JLabel, JTextField, JPanel, and other GUI classes.

Recommended: Install a current Long-Term Support JDK and a compatible Apache NetBeans release. In NetBeans, check Tools → Java Platforms to confirm that the JDK is detected.

Topic 03

Important Java GUI concepts

Class

A blueprint that groups data and behavior. A JFrame window is normally represented by a class.

Object

An instance of a class. new StudentForm() creates one window object.

Inheritance

extends JFrame gives your class the features of a standard Swing window.

Component

A visual control such as a label, text field, button, combo box, or table.

Container

A component that holds other components. JFrame and JPanel are common containers.

Event

An action such as clicking a button, choosing an item, or typing in a field.

Topic 10

Arrange components with layout managers

A layout manager automatically positions and sizes components. This is more reliable than using fixed coordinates, especially on different screens and operating systems.

BorderLayout

Places components in North, South, East, West, and Center regions. Good for the main window.

FlowLayout

Places components in a row and wraps them when necessary. Good for button groups.

GridLayout

Creates equally sized cells in rows and columns. Good for keypads or simple dashboards.

GridBagLayout

Creates flexible rows and columns. Powerful for forms but requires more configuration.

GroupLayout

The default choice of the NetBeans GUI Builder. It aligns components visually in parallel and sequential groups.

Handle button events

Event-driven programs wait for the user to perform an action. The listener contains the instructions that run after the event occurs.

Save button event
saveButton.addActionListener(event -> {
    String name = nameField.getText().trim();

    if (name.isEmpty()) {
        JOptionPane.showMessageDialog(
            this,
            "Please enter the student's name.",
            "Missing Information",
            JOptionPane.WARNING_MESSAGE
        );
        nameField.requestFocus();
        return;
    }

    JOptionPane.showMessageDialog(
        this,
        "Student saved successfully!"
    );
});
User clicks→Event occurs→Listener runs→Interface responds

Topic 12 • New lesson

Validate input and prevent program crashes

Validation checks user input before the program uses it. A friendly message should explain what is wrong, then return focus to the field that needs correction.

Validate text and a number
String name = nameField.getText().trim();
String ageText = ageField.getText().trim();

if (name.isEmpty()) {
    JOptionPane.showMessageDialog(this, "Please enter a name.");
    nameField.requestFocus();
    return;
}

try {
    int age = Integer.parseInt(ageText);
    if (age < 1 || age > 120) {
        throw new IllegalArgumentException("Age is outside the allowed range.");
    }
} catch (NumberFormatException error) {
    JOptionPane.showMessageDialog(this, "Age must be a whole number.");
    ageField.requestFocus();
    return;
} catch (IllegalArgumentException error) {
    JOptionPane.showMessageDialog(this, error.getMessage());
    ageField.requestFocus();
    return;
}
Remember: Text fields always return text. Convert the value only after checking that it is present, and catch conversion errors instead of allowing the application to stop.

Topic 13

Complete JFrame example

This example is written by code rather than generated Design-view code, so learners can see every part of the window. Save it as StudentRegistrationApp.java.

StudentRegistrationApp.java
package studentapp;

import java.awt.*;
import javax.swing.*;
import javax.swing.border.EmptyBorder;

public class StudentRegistrationApp extends JFrame {
    private final JTextField nameField = new JTextField(20);
    private final JTextField emailField = new JTextField(20);
    private final JComboBox<String> courseBox = new JComboBox<>(
        new String[]{"BS Information Technology", "BS Computer Science", "BS Information Systems"}
    );
    private final JTextArea resultArea = new JTextArea(6, 24);

    public StudentRegistrationApp() {
        setTitle("Student Registration App");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setMinimumSize(new Dimension(560, 480));

        JPanel root = new JPanel(new BorderLayout(16, 16));
        root.setBorder(new EmptyBorder(24, 24, 24, 24));

        JLabel title = new JLabel("Student Registration");
        title.setFont(new Font("SansSerif", Font.BOLD, 24));
        root.add(title, BorderLayout.NORTH);

        JPanel form = new JPanel(new GridLayout(3, 2, 12, 12));
        form.add(new JLabel("Complete name:"));
        form.add(nameField);
        form.add(new JLabel("Email address:"));
        form.add(emailField);
        form.add(new JLabel("Course:"));
        form.add(courseBox);

        resultArea.setEditable(false);
        resultArea.setLineWrap(true);
        resultArea.setWrapStyleWord(true);

        JButton saveButton = new JButton("Save Student");
        JButton clearButton = new JButton("Clear Form");
        saveButton.addActionListener(event -> saveStudent());
        clearButton.addActionListener(event -> clearForm());

        JPanel actions = new JPanel(new FlowLayout(FlowLayout.RIGHT));
        actions.add(clearButton);
        actions.add(saveButton);

        JPanel center = new JPanel(new BorderLayout(12, 12));
        center.add(form, BorderLayout.NORTH);
        center.add(new JScrollPane(resultArea), BorderLayout.CENTER);
        center.add(actions, BorderLayout.SOUTH);
        root.add(center, BorderLayout.CENTER);

        setContentPane(root);
        pack();
        setLocationRelativeTo(null);
    }

    private void saveStudent() {
        String name = nameField.getText().trim();
        String email = emailField.getText().trim();
        String course = (String) courseBox.getSelectedItem();

        if (name.isEmpty() || email.isEmpty()) {
            JOptionPane.showMessageDialog(this,
                "Name and email are required.",
                "Validation Error",
                JOptionPane.WARNING_MESSAGE);
            return;
        }

        resultArea.setText("REGISTRATION SUMMARY\n\n"
            + "Name: " + name + "\n"
            + "Email: " + email + "\n"
            + "Course: " + course);
    }

    private void clearForm() {
        nameField.setText("");
        emailField.setText("");
        courseBox.setSelectedIndex(0);
        resultArea.setText("");
        nameField.requestFocus();
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new StudentRegistrationApp().setVisible(true);
        });
    }
}
Why SwingUtilities.invokeLater()? Swing components should be created and updated on the Event Dispatch Thread. This keeps interface events safe and orderly.

Topic 17

Common errors and quick fixes

“Cannot find symbol”

Check spelling, capitalization, imports, and whether the variable was declared in the correct scope.

“Main class not found”

Confirm that the class has a correct public static void main(String[] args) method. Then set it under Project Properties → Run → Main Class.

The JFrame opens but is empty

Make sure components were added to a visible container, call pack() or setSize(), and finally call setVisible(true).

The button does nothing

Confirm that an ActionListener is attached to the correct button and that the code is inside the event handler.

GUI Builder code cannot be edited

The gray guarded section is generated. Return to Design view and update components or properties there.

The JAR will not open

Check the configured main class and Java version. Run it from a terminal to see the detailed error message.

Topic 19

Check your understanding

1. What is the difference between the JDK and NetBeans?

The JDK provides the compiler and Java tools. NetBeans is an IDE that organizes those tools through a code editor, project manager, GUI Builder, debugger, and other features.

2. What does extends JFrame mean?

The new class inherits the data and behavior of JFrame, allowing it to work as a Swing window.

3. Why should a layout manager be used?

It arranges and resizes components more reliably across different window sizes, fonts, and operating systems.

4. Where should button-click instructions be written?

Inside an ActionListener or the button's generated actionPerformed event method.

5. Where is the built JAR normally located in an Ant project?

Inside the project's dist folder after a successful Clean and Build.

6. Why is trim() useful when checking a text field?

It removes spaces from the beginning and end, so an input containing only spaces is correctly treated as empty.

7. Why should Integer.parseInt() be placed inside a try-catch block?

Typing letters or an invalid number causes a NumberFormatException. Catching it lets the program show a helpful message instead of crashing.

8. What is the role of a DefaultTableModel?

It stores the JTable's column names and row data and provides methods such as addRow() for updating the displayed records.
