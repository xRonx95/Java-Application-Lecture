TOPIC 01

FOUNDATION

What is Apache NetBeans?

Apache NetBeans is a free, open-source Integrated Development Environment—or IDE. It combines the tools a programmer needs in one application.

Simple: Imagine if you had to write a letter in one app, spell-check it in another app, and print it using a totally separate program. That would be annoying. An IDE like NetBeans puts all these separate jobs into ONE app instead.

Instead of writing code in one application, compiling it in a terminal, and looking for errors somewhere else, an IDE puts these tasks into one organized workspace. NetBeans is best known for Java, but can also support PHP, HTML, CSS, JavaScript, C/C++, and other technologies.

Simple explanation

Think of NetBeans as a digital workshop: the editor is the workbench, the compiler is the quality checker, the debugger is the magnifying glass, and the project window is the organizer.

"Compiling" just means turning your written code into something the computer can actually run. Without an IDE, you'd write code in one window, jump to a black terminal screen to compile it, then hunt around to find out what went wrong. NetBeans keeps all of that in one place so you're not constantly switching tools.

Simple: A basic text editor (like Notepad) just lets you type. It doesn't check your code, doesn't help you fix errors, and doesn't run your program. An IDE does all of that AND lets you type — that's the big difference. It's like the difference between a plain notebook and a notebook that also grades your homework and points out your mistakes.

IDE vs. basic text editor

Basic text editor
  • Mainly edits plain text
  • Tools are installed separately
  • Little awareness of project structure
NetBeans IDE
  • Understands project structure
  • Suggests and checks code
  • Builds, runs, and debugs in one place

TOPIC 02

THE INTERFACE

Know your workspace

NetBeans divides its tools into windows. Knowing each area makes the IDE easier to use.

A

Menu & toolbar

Commands for creating, saving, building, running, debugging, and configuring projects.

B

Projects window

Shows source packages, libraries, tests, resources, and the logical project structure.

C

Source editor

The main coding area, with syntax colors, line numbers, tabs, hints, and error marks.

D

Navigator

Lists classes, methods, fields, and members in the selected source file.

E

Output window

Displays program output, compiler messages, test results, and build information.

F

Services window

Connects to databases, servers, repositories, and development services.

Teacher prompt

Ask: “If a program does not produce the expected result, which window would you check first—and why?”

TOPIC 03

PROJECT WORKFLOW

From idea to running program

A project is a managed collection of source code, libraries, settings, and output files.

  1. 1
    Create

    Select File → New Project, choose a project type, and give it a clear name.

  2. 2
    Code

    Add packages and classes, then write the program in the Source Editor.

  3. 3
    Build

    Compile the source. Correct errors reported in the Output window.

  4. 4
    Run

    Press F6 to run the main project and examine the result.

  5. 5
    Test & debug

    Compare actual and expected behavior, then locate and correct problems.

TOPIC 05

DEBUGGING

Find the cause, not just the error

Debugging means pausing a program while it runs so you can inspect its behavior one instruction at a time.

  1. 1
    Set a breakpoint

    Click beside a line number. Execution pauses before that line runs.

  2. 2
    Start Debug Project

    Use Ctrl + F5 to run the project in debugging mode.

  3. 3
    Inspect variables

    Check current values and compare them with the values you expected.

  4. 4
    Step through code

    Use Step Over, Step Into, Step Out, and Continue to control execution.

Know the difference

A syntax error breaks language rules, a runtime error occurs during execution, and a logic error produces a wrong result even though the program runs.

TOPIC 08

JAVA ESSENTIALS

Build programs with input and decisions

The Grade Checker activity uses four ideas: variables, keyboard input, an if/else decision, and output.

1

Variables store values

String name = "Ana";
int grade = 88;

Choose a data type and a meaningful variable name.

2

Scanner reads input

Scanner input =
  new Scanner(System.in);

Import java.util.Scanner before the class.

3

if/else decides

if (grade >= 75) {
  // passed
} else { // improve
}

The condition is true when the grade is 75 or higher.

4

println shows output

System.out.println(
  name + " passed.");

Join text and variable values with the + operator.

COMPLETE EXAMPLE

Student Grade Checker

Copy carefully, compare every bracket and semicolon, then test with 74, 75, and 100.

import java.util.Scanner;

public class GradeChecker {
  public static void main(String[] args) {
    Scanner input = new Scanner(System.in);

    System.out.print("Student name: ");
    String name = input.nextLine();
    System.out.print("Numeric grade: ");
    int grade = input.nextInt();

    if (grade >= 75) {
      System.out.println(name + " — Passed");
    } else {
      System.out.println(name + " — Needs Improvement");
    }
  }
}

TOPIC 09

ERRORS & TESTING

Read the clue, fix one problem at a time

Do not guess randomly. Start with the first error in the Output window, locate its line number, correct it, and run the program again.

▶ Run Example · Topic 09

Run boundary tests after fixing the comparison

The corrected condition uses >= 75. Run several values so students can compare actual output with the test plan.

Java code

public class BoundaryTest {
    public static void main(String[] args) {
        int[] grades = {74, 75, 88, 100};

        for (int grade : grades) {
            String result = grade >= 75 ? "Passed" : "Needs Improvement";
            System.out.println(grade + " → " + result);
        }
    }
}

Expected Output

run: 74 → Needs Improvement 75 → Passed 88 → Passed 100 → Passed BUILD SUCCESSFUL
Logic-error check: if 75 prints “Needs Improvement,” inspect the comparison operator and change > to >=.

EVALUATION

Advantages and limitations

+ Why choose NetBeans?

  • Free and open-source
  • Strong Java support
  • Integrated coding and debugging tools
  • Works on Windows, macOS, and Linux
  • Supports organized projects
  • Expandable with plugins

– What should learners know?

  • Uses more memory than a text editor
  • May start slowly on older computers
  • Many panels can feel complex at first
  • Some languages need plugins
  • Large projects need good organization
  • Shortcuts take time to learn

Success checklist

KNOWLEDGE CHECK

Review questions

Answer first, then open each question to check.

01What does IDE mean, and what problem does it solve?

IDE means Integrated Development Environment. It combines tools for editing, building, running, testing, and debugging software in one workspace.

02Which window displays compiler messages and program results?

The Output window displays build messages, errors, test results, and text printed by the program.

03What is the purpose of a breakpoint?

A breakpoint pauses execution so a developer can inspect values and follow the program's behavior.

04How is a logic error different from a syntax error?

A syntax error breaks language rules. A logic error allows the program to run but gives an incorrect result.

05Name three NetBeans productivity tools.

Examples: code completion, refactoring, templates, formatting, quick fixes, Git integration, and the debugger.

06Why must a JDK be installed before creating Java projects?

The JDK provides the Java compiler and other development tools that NetBeans uses to build and run Java programs.

07What does Scanner do in the Grade Checker?

Scanner reads values entered by the user through the keyboard, such as the student name and numeric grade.

08Why should the grade 75 be included in the test plan?

It is the exact boundary between the two results. Testing it confirms that the program uses greater than or equal to, not only greater than.

09What is the best first action after NetBeans reports several errors?

Read and fix the first reported error, because one early syntax problem can cause several additional messages.
