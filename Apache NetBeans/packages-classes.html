Beginner example: decisions, loops, and methods

GradeAnalyzer.java
public class GradeAnalyzer {
    static String getRemark(double grade) {
        if (grade >= 90) return "Outstanding";
        if (grade >= 75) return "Passed";
        return "Needs improvement";
    }

    public static void main(String[] args) {
        double[] grades = {88, 93, 79, 91};
        double total = 0;

        for (double grade : grades) {
            total += grade;
        }

        double average = total / grades.length;
        System.out.println("Average: " + average);
        System.out.println("Remark: " + getRemark(average));
    }
}
Beginner checkpoint: Explain every line of the example, change the grades, add highest/lowest calculations, and reject values below 0 or above 100.

Lesson 6 deep dive: Java packages

A package is a named group of related classes, interfaces, and subpackages. Think of it as a labeled folder that keeps a project clean and prevents two classes with the same name from colliding.

Simple analogy: A school is the project, departments are packages, teachers are classes, and individual teachers are objects.

Package declaration and import

Student.java
package lessonmodule.models;

import javax.swing.JOptionPane;

public class Student {
    // Class members go here
}

Why packages matter

  • Keep source files organized
  • Prevent class-name conflicts
  • Control class accessibility
  • Make code easier to reuse

Naming convention

Package names normally use lowercase letters. In larger projects, a reversed domain name is often used.

com.school.lessonmodule

Suggested project structure

📁 PackagesClassesLesson 📁 Source Packages 📦 lessonmodule ☕ PackagesClassesFrame.java 📦 lessonmodule.models ☕ Student.java

Access modifiers

Access modifiers determine where a class or member can be used. Keeping fields private and exposing them through methods is called encapsulation.

ModifierSame classSame packageSubclassEverywhere
privateYesNoNoNo
defaultYesYesNo*No
protectedYesYesYesNo
publicYesYesYesYes

*A subclass in another package can access an inherited protected member, but default access remains package-only.

Lesson 14 preview: Building a JFrame application

JFrame is Swing's main top-level window. The sample below creates a small student introduction application and demonstrates packages, objects, events, and GUI components.

1

Create a projectIn NetBeans, select File → New Project → Java Application.

2

Create a packageRight-click Source Packages → New → Java Package. Name it lessonmodule.

3

Add the classCreate PackagesClassesFrame.java, then paste the supplied Java code.

4

Run the programRight-click the file and choose Run File, or press Shift + F6.

Important: The package name must match the package folder, and the public class name must match the Java filename exactly.

How the application works

  1. The class extends JFrame, so it becomes a window.
  2. The constructor sets the title, size, close behavior, and layout.
  3. Swing components such as JTextField, JButton, and JLabel are added to panels.
  4. An action listener runs when the user clicks the button.
  5. SwingUtilities.invokeLater starts the interface safely on Swing's event thread.

Mini-lesson 1 — Safe keyboard input with Scanner

Never assume the user will type the correct data. Check the input before converting or using it.

SafeInput.java
import java.util.Scanner;

public class SafeInput {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int age;

        while (true) {
            System.out.print("Enter age (10-100): ");
            if (input.hasNextInt()) {
                age = input.nextInt();
                if (age >= 10 && age <= 100) break;
            } else {
                input.next(); // discard invalid text
            }
            System.out.println("Invalid age. Try again.");
        }

        System.out.println("Accepted age: " + age);
    }
}
Practice: Add validated inputs for a grade from 0–100 and a non-empty student name.

Mini-lesson 2 — Enums and the Java date-time API

Use an enum when a value must come from a small fixed list. Use LocalDate for a date without a time zone.

EnrollmentSchedule.java
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

enum EnrollmentStatus { OPEN, CLOSED, WAITLIST }

public class EnrollmentSchedule {
    public static void main(String[] args) {
        LocalDate deadline = LocalDate.of(2026, 8, 31);
        LocalDate today = LocalDate.now();
        EnrollmentStatus status = today.isAfter(deadline)
                ? EnrollmentStatus.CLOSED
                : EnrollmentStatus.OPEN;

        DateTimeFormatter format = DateTimeFormatter.ofPattern("MMMM d, yyyy");
        System.out.println("Deadline: " + deadline.format(format));
        System.out.println("Status: " + status);
    }
}
Practice: Add a WAITLIST state and use ChronoUnit.DAYS.between() to show the number of days remaining.

Mini-lesson 4 — Call a REST API with Java HttpClient

An API request can fail because of connectivity, permission, invalid JSON, or a server problem. Always check the HTTP status code before using the response body.

ApiClient.java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class ApiClient {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.example.com/students/1"))
                .header("Accept", "application/json")
                .GET()
                .build();

        HttpResponse<String> response = client.send(
                request, HttpResponse.BodyHandlers.ofString());

        if (response.statusCode() == 200) {
            System.out.println(response.body());
        } else {
            System.out.println("Request failed: " + response.statusCode());
        }
    }
}
Important: The example URL is a placeholder. Replace it with an API your teacher approves. Never place a secret API key directly in source code.
Practice: Explain what GET, POST, PUT, and DELETE usually do, then handle status codes 200, 404, and 500 with different user-friendly messages.
