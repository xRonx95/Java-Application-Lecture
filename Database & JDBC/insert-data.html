Lesson 05 · Guided Laboratory

Insert Form Data into MySQL using JDBC

Create a professional Java web workflow that receives student information, validates it, and stores it securely with a PreparedStatement.

Level IntermediateTime 2–3 hoursOutput Working insert form

Part I

Essential concepts

Understand the process before writing the code.
01

Relational database

Stores related records in tables composed of rows and columns. Keys identify and connect records.

02

JDBC

The Java API that communicates with a database through a vendor-specific driver such as Connector/J.

03

PreparedStatement

A parameterized SQL statement that separates the query structure from user-supplied values.

04

HTTP POST

The form method used to send data in the request body for a server-side operation that changes data.

Install and verify the tools

  2. Install Apache Tomcat 10 or later.
  3. Install and start MySQL Server.
  4. Download MySQL Connector/J.
  5. Add the driver JAR to WEB-INF/lib.

Step 4

Create the JDBC connection

public class DatabaseConnection {
  private static final String URL =
      "jdbc:mysql://localhost:3306/school_db";

  public static Connection getConnection()
      throws SQLException {
    return DriverManager.getConnection(
        URL, "app_user", "secure_password");
  }
}
Professional practice: Store real credentials in environment variables or protected server configuration, not in public source files.

Step 5

Insert the data safely

String sql = "INSERT INTO students " +
  "(full_name, email, course) VALUES (?, ?, ?)";

try (Connection con = DatabaseConnection.getConnection();
     PreparedStatement ps = con.prepareStatement(sql)) {
  ps.setString(1, request.getParameter("fullName").trim());
  ps.setString(2, request.getParameter("email").trim());
  ps.setString(3, request.getParameter("course"));
  int rows = ps.executeUpdate();
}
Security rule: Never concatenate form input into SQL. Use placeholders and validate every field on the server.
