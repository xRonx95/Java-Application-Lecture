Introduction

Lesson Overview

MySQL Connector/J is the official JDBC driver for MySQL. It allows a Java program to send SQL commands to a MySQL server and receive the results in a form that Java can process.

Without the connector, the Java application and the database cannot communicate using JDBC. The connector acts as a translator between Java's standard database interfaces and the MySQL network protocol.

i

Scope of this lesson

This module uses a local MySQL or MariaDB server, Java, JDBC, and Apache NetBeans. The same JDBC principles also apply to other Java IDEs.

Foundation

Core Concepts

API

JDBC

Java Database Connectivity is the standard Java API for opening connections, executing SQL, and processing database results.

JAR

Connector/J

The MySQL JDBC driver packaged as a Java archive. It implements JDBC for communication with MySQL.

URL

Connection URL

An address such as jdbc:mysql://localhost:3306/school_db that identifies the server, port, and database.

The locations where Java searches for compiled classes and libraries required by the application.

An active session between the Java application and the database server.

PS

A parameterized SQL statement that improves clarity and helps prevent SQL injection.

System Flow

How the Connection Works

The application does not communicate with MySQL directly. Java code uses JDBC interfaces, Connector/J translates those calls, and the database server executes the SQL.

1. RequestJava calls the JDBC API.
2. TranslationConnector/J converts the call.
3. ExecutionMySQL runs the SQL statement.
4. ResultJDBC returns data or an update count.

Guided Demonstration

Step-by-Step Installation and Connection

Complete each step in order. Read the checkpoint before proceeding to the next step.

1

Official Package

Download MySQL Connector/J

  1. Open the official MySQL Connector/J download page.
  2. Select the platform-independent package when manually adding a JAR to NetBeans.
  3. Download the archive to a known location such as Downloads.
  4. Use the current release that is compatible with the JDK and MySQL Server used by your institution.
Checkpoint: A Connector/J ZIP or TAR archive should appear in the Downloads folder.
2

Library File

Extract and Locate the JAR File

  1. Right-click the downloaded archive and select Extract All.
  2. Open the extracted folder.
  3. Locate the driver file named similar to mysql-connector-j-x.y.z.jar.
  4. Move the extracted package to a permanent folder. Do not leave the only copy inside a temporary archive location.
Checkpoint: The selected filename ends in .jar and begins with mysql-connector-j.
3

Project Setup

Create or Open a Java Project

  1. Open Apache NetBeans.
  2. Select File → New Project.
  3. Choose Java Application, then select Next.
  4. Name the project MySQLConnectorLesson and complete the wizard.
  5. Create a package named school.database.
4

Classpath Configuration

Add Connector/J to the Project Libraries

  1. In the Projects panel, right-click the project and select Properties.
  2. Open the Libraries category.
  3. Select Add JAR/Folder.
  4. Browse to the extracted Connector/J folder and select the JAR file.
  5. Select Open, then OK.
Checkpoint: Expand the project's libraries or dependencies and confirm that the Connector/J JAR is listed.

Database Preparation

Create the Practice Database and Table

Open phpMyAdmin or the MySQL command line and execute the following SQL. The example uses fictional classroom data only.

CREATE DATABASE IF NOT EXISTS school_db
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE school_db;

CREATE TABLE IF NOT EXISTS students (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  student_number VARCHAR(20) NOT NULL UNIQUE,
  full_name VARCHAR(120) NOT NULL,

Checkpoint: The school_db database contains a students table with five columns.

Reusable Configuration

Create the Database Connection Class

Create DatabaseConnection.java inside the school.database package. Update the username and password to match the classroom server.

Java · DatabaseConnection.java
package school.database;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public final class DatabaseConnection {
    private static final String URL =
        "jdbc:mysql://localhost:3306/school_db"
        + "?useSSL=false&serverTimezone=UTC";
    private static final String USER = "root";
    private static final String PASSWORD = "";

    private DatabaseConnection() {
        // Prevent this utility class from being instantiated.
    }

    public static Connection open() throws SQLException {
        return DriverManager.getConnection(URL, USER, PASSWORD);
    }
}
!

Credentials require protection

Hard-coded credentials are acceptable only for a controlled beginner exercise. In a real application, load secrets from protected configuration or environment variables and use a database account with only the permissions it needs.

Connection Test

Open and Verify the Connection

Create ConnectionTest.java in the same package.

Java · ConnectionTest.java
package school.database;

import java.sql.Connection;
import java.sql.SQLException;

public class ConnectionTest {
    public static void main(String[] args) {
        try (Connection connection = DatabaseConnection.open()) {
            System.out.println("Connection successful.");
            System.out.println("Database: "
                + connection.getCatalog());
        } catch (SQLException exception) {
            System.err.println("Connection failed.");
            System.err.println("SQLState: "
                + exception.getSQLState());
            System.err.println("Message: "
                + exception.getMessage());
        }
    }
}
  1. Save both Java files.
  2. Right-click ConnectionTest.java and select Run File.
  3. Read the Output window.
  4. If the connection fails, record the full message before changing the code.
Expected output: Connection successful. followed by Database: school_db.

Alternative Setup

Add Connector/J with Maven

For a Maven project, add the official coordinates below to pom.xml. Replace x.y.z with a compatible current version selected by the teacher or project team.

    <artifactId>mysql-connector-j</artifactId>
    <version>x.y.z</version>
</dependency>

Choose one dependency method

Application Development

Execute SQL Safely with PreparedStatement

A successful connection is only the beginning. Applications should use parameterized statements when inserting, searching, updating, or deleting values supplied by a user.

Java · safe insert
String sql = "INSERT INTO students "
        + "(student_number, full_name, program) "
        + "VALUES (?, ?, ?)";

try (Connection connection = DatabaseConnection.open();
     PreparedStatement statement =
         connection.prepareStatement(sql)) {

    statement.setString(1, "2026-001");
    statement.setString(2, "Sample Student");
    statement.setString(3, "BS Information Technology");

    int rowsAdded = statement.executeUpdate();
    System.out.println("Rows added: " + rowsAdded);
} catch (SQLException exception) {
    System.err.println("Insert failed: "
        + exception.getMessage());
}

Recommended Connection Practices

  • Use try-with-resources so connections, statements, and result sets close automatically.
  • Use PreparedStatement for all user-supplied values.
  • Do not show database passwords or detailed server errors to end users.
  • Use a dedicated database account with the minimum required privileges.
  • Keep connection settings in one configuration class or protected configuration source.
  • Log technical details securely for troubleshooting.
  • Use encrypted connections and verified certificates for remote production databases.

Problem Solving

Common Errors and Solutions

Error or SymptomLikely CauseRecommended Check
No suitable driverConnector/J is not on the runtime classpath or the URL is invalid.Confirm that the JAR or Maven dependency is present and the URL begins with jdbc:mysql:.
ClassNotFoundExceptionThe driver class cannot be loaded.Re-add the connector, clean the project, and rebuild it. The modern driver class is com.mysql.cj.jdbc.Driver.
Communications link failureMySQL is stopped, the port is wrong, or the host is unreachable.Start MySQL and verify the host and port. The common local port is 3306, but the installation may use another port.
Access denied for userThe username, password, host permission, or account privileges are incorrect.Test the same credentials in an approved MySQL client and verify account permissions.
Unknown databaseThe database name is misspelled or has not been created.Check the schema name in MySQL and in the JDBC URL.
Time-zone exceptionThe client and server time-zone configuration cannot be resolved.Use an appropriate serverTimezone value approved for the application.
Authentication plugin errorThe connector and server authentication configuration are incompatible.Use compatible supported releases and review the official Connector/J compatibility documentation.

Professional Diagnostic Sequence

  1. Read and record the complete exception message and SQLState.
  2. Confirm that MySQL is running and listening on the expected port.
  3. Verify the host, port, database name, username, and password.
  4. Confirm that Connector/J is present in the runtime classpath.
  5. Test the account and database using an approved database client.
  6. Change only one item at a time, then rerun the test.

Teacher's Answer Guide

1. B. Connector/J implements JDBC communication for MySQL.

2. B. The JDBC URL identifies the database endpoint.

3. It separates SQL structure from values, helps prevent SQL injection, and makes parameter handling explicit.

4. Confirm the server is running, verify host and port, check network access, then confirm the JDBC URL.

5. Closing connections releases limited database and network resources and prevents resource leaks.

Terminology

Glossary

Classpath
The set of locations Java searches for required classes and libraries.
Connection
An active communication session between an application and a database server.
Driver
Software that implements a standard interface for a specific database system.
JAR
A Java archive used to distribute compiled classes and related resources.
JDBC
The standard Java API for relational database operations.
JDBC URL
A structured address describing how to reach a database.
MySQL Connector/J
The official JDBC driver for MySQL.
PreparedStatement
A precompiled, parameterized SQL statement represented by a JDBC object.
ResultSet
A JDBC object that represents rows returned by a query.
SQLState
A standardized code that categorizes a database error or condition.
