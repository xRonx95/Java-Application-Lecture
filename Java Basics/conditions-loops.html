1. Understanding Control Flow

By default, Java executes statements from top to bottom. Selection chooses which path to run, while iteration repeats a block of code.

Sequence

Instructions run once in their written order.

Selection

if and switch choose among paths.

Iteration

while, do-while, and for repeat work.

Boolean condition

An expression that evaluates to exactly true or false.

2. if, else if, and else

One-way decision

if statementRuns only when true
if (temperature > 37.5) {
    System.out.println("High temperature detected.");
}

Two-way decision

if-elseExactly one branch runs
if (grade >= 75) {
    System.out.println("Passed");
} else {
    System.out.println("Needs improvement");
}

Multi-way decision

Grading scaleFirst true branch wins
if (grade >= 90) {
    System.out.println("Excellent");
} else if (grade >= 85) {
    System.out.println("Very Good");
} else if (grade >= 75) {
    System.out.println("Passed");
} else {
    System.out.println("Failed");
}
Order matters: Check the most restrictive or highest range first. If grade >= 75 came first, a grade of 95 would match it and skip “Excellent.”

Nested if

Decision inside a decisionJava
if (usernameIsCorrect) {
    if (passwordIsCorrect) {
        System.out.println("Login successful");
    } else {
        System.out.println("Incorrect password");
    }
}

3. switch Statements and Expressions

Use switch when one value is compared with several exact alternatives.

Traditional switch

Menu selectionbreak prevents fall-through
switch (choice) {
    case 1:
        System.out.println("View profile");
        break;
    case 2:
        System.out.println("Edit profile");
        break;
    default:
        System.out.println("Invalid choice");
}

Modern switch expression

Switch expressionJava 14+
String dayType = switch (day) {
    case "SATURDAY", "SUNDAY" -> "Weekend";
    case "MONDAY", "TUESDAY", "WEDNESDAY",
         "THURSDAY", "FRIDAY" -> "Weekday";
    default -> "Unknown";
};
Choose clearly: Use if for ranges and complex conditions. Use switch for several exact matches against one value.

4. The while Loop

A while loop checks its condition before every iteration. It may run zero times. Use it when the number of repetitions is not known in advance.

Counter-controlled whileOutput: 1 2 3 4 5
int count = 1;

while (count <= 5) {
    System.out.println(count);
    count++;
}

Sentinel-controlled loop

A sentinel is a special value that signals the end of input, such as -1.

Repeat until -1Pattern
int number = input.nextInt();

while (number != -1) {
    System.out.println("You entered: " + number);
    number = input.nextInt();
}
Infinite loop: If the condition never becomes false—often because the update is missing—the loop never ends. Always identify initialization, condition, and update.

5. The do-while Loop

A do-while loop checks its condition after the body, so it always runs at least once. This is useful for menus and input validation.

Input validationRuns at least once
int rating;

do {
    System.out.print("Enter a rating from 1 to 5: ");
    rating = input.nextInt();
} while (rating < 1 || rating > 5);

System.out.println("Thank you!");

Notice the required semicolon after the final while (condition);.

6. The for Loop

A for loop keeps initialization, condition, and update together. It is best when the number of repetitions is known or controlled by a counter.

Count from 1 to 5initialization; condition; update
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Common patterns

Loop patternsJava
// Count backward
for (int i = 10; i >= 1; i--) { ... }

// Count by twos
for (int i = 0; i <= 20; i += 2) { ... }

// Visit array indexes
for (int i = 0; i < scores.length; i++) { ... }
Off-by-one error: An array of length 5 has indexes 0 through 4. Use i < array.length, not i <= array.length.

7. The Enhanced for Loop

The enhanced for loop, also called for-each, reads each value from an array or collection without managing an index.

For-eachRead every score
int[] scores = {88, 91, 95};
int total = 0;

for (int score : scores) {
    total += score;
}

double average = (double) total / scores.length;

Use a regular for loop when you need the index or want to replace elements. Use for-each when you only need each value.

8. break and continue

break

Immediately ends the nearest loop or switch.

continue

Skips the remaining statements in the current iteration and moves to the next one.

Search with breakStop after finding the target
for (int number : numbers) {
    if (number == target) {
        System.out.println("Found!");
        break;
    }
}
Filter with continuePrint odd numbers only
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;
    }
    System.out.println(i);
}

9. Nested Loops and Tracing

A nested loop is a loop inside another loop. The inner loop completes all its iterations for each single iteration of the outer loop.

3 × 4 grid12 total iterations
for (int row = 1; row <= 3; row++) {
    for (int column = 1; column <= 4; column++) {
        System.out.print("* ");
    }
    System.out.println();
}

How to trace a loop

  1. Write the starting values of all variables.
  2. Evaluate the condition.
  3. If true, execute the body one statement at a time.
  4. Apply the update.
  5. Repeat until the condition becomes false.
Teaching technique: Use a trace table with columns for iteration, condition, variable values, and output. It makes loop behavior visible instead of abstract.

Practice and Review

Activity: Grade Analyzer

Ask how many grades will be entered. Use a loop to read the grades, calculate the average, count passing grades, and record the highest grade. Use a condition to print the final performance description.

Challenge activities

  • Print a multiplication table from 1 to 10 using nested loops.
  • Create a menu that repeats until the user chooses Exit.
  • Ask for a positive number repeatedly and reject invalid input.
  • Print all numbers from 1 to 100 that are divisible by both 3 and 5.

Quick check

1. Which loop always runs at least once?

The do-while loop, because its condition is checked after the body.

2. When is for-each better than a regular for loop?

When you want to read every item and do not need its index or need to replace it.

3. What is the difference between break and continue?

break exits the loop completely; continue skips only the rest of the current iteration.
