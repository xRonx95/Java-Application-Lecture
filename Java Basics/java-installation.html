Tools for developing Java programs, including javac, java, and documentation tools.

JRE Java Runtime Environment

Runtime libraries and supporting files used when a Java application runs.

Before you begin

Installation requirements

Which version should the class use?

Use the JDK version required by your teacher or school. For a new class, an LTS release such as JDK 21 or JDK 25 is a practical choice. Every student should use the same major version whenever possible.

04

Guided procedure

Install the JDK on Windows

Step 1

Open an official download page

Choose one trusted JDK provider. Do not download Java installers from unknown websites.

Oracle JDK Downloads ↗ Eclipse Temurin Downloads ↗
Step 2

Select the correct package

  • Operating system: Windows
  • Architecture: x64 for most modern Windows computers
  • Package: JDK installer (.msi or .exe)

To check your architecture: Settings → System → About → System type.

Step 3

Run the installer

  1. Open the downloaded installer.
  2. Select Yes if Windows asks for permission.
  3. Choose Next and keep the default installation folder.
  4. If available, enable Set JAVA_HOME and Add to PATH.
  5. Select Install, then Finish.
Step 4

Locate the installed JDK

The folder normally looks similar to one of these examples:

C:\Program Files\Java\jdk-25
C:\Program Files\Eclipse Adoptium\jdk-25...

Your exact folder name may be different because it includes the installed version.

05

System configuration

Set JAVA_HOME and Path

Some installers configure these automatically. If java or javac is not recognized, use the manual steps below.

  1. Open Environment Variables. Search Windows for “environment variables,” then select Edit the system environment variables.
  2. Create JAVA_HOME. Under System variables, select New. Enter JAVA_HOME as the name and your JDK folder as the value.
  3. Update Path. Edit the Path system variable and add %JAVA_HOME%\bin.
  4. Save and reopen Command Prompt. Select OK in every window. Close old terminals so they can load the new settings.
Important:

JAVA_HOME points to the JDK folder—not to its bin folder. The Path entry adds \bin.

06

Installation check

Verify Java in Command Prompt

Open a new Command Prompt and run each command separately:

Command 1Check the Java launcher
java -version
Command 2Check the Java compiler
javac -version
Command 3Check JAVA_HOME
echo %JAVA_HOME%
✓
Successful result

If the commands display version numbers and a valid JDK folder, Java is installed correctly.

Common problems

Troubleshooting guide

“java” is not recognized as a command.

Check that %JAVA_HOME%\bin is in Path. Save the change, close Command Prompt, and open a new one.

java -version works, but javac -version does not.

You may have only a runtime or an incorrect Path entry. Install a full JDK and point JAVA_HOME to that JDK.

The wrong Java version appears.

Windows may find an older Java folder first. Move %JAVA_HOME%\bin above older Java entries in Path or remove obsolete entries.

“Could not find or load main class” appears.

Run the command from the folder containing the .class file. Use java HelloJava without .class.

The public class name and filename do not match.

A public class named HelloJava must be saved in a file named HelloJava.java, including matching capitalization.

09

Knowledge check

Review questions

1. Which component contains the compiler used to create Java programs?

  1. JVM
  2. JDK
  3. Web browser
  4. Command Prompt
Show answer

B. JDK. It includes development tools such as javac.

2. What does the javac command do?

  1. Runs bytecode
  2. Downloads Java
  3. Compiles source code
  4. Edits Path
Show answer

C. Compiles source code. It turns a .java file into a .class file.

3. What value should be added to the Windows Path?

  1. %JAVA_HOME%\bin
  2. HelloJava.java
  3. C:\Windows
  4. java -version
Show answer

A. %JAVA_HOME%\bin. This lets Windows find Java command-line tools.

Lesson complete

Key takeaways

  • Install a full JDK to develop Java applications.
  • The JDK includes the tools needed to compile and run Java code.
  • JAVA_HOME points to the JDK, while Path includes its bin folder.
  • Use java -version and javac -version to verify the installation.
  • A successful first program confirms the entire setup works.
