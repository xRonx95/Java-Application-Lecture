Getting Started

What is Java?

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible.

Java was created by James Gosling, along with his team at Sun Microsystems. Gosling began work on it in 1991 (originally under the name "Oak") and it was officially released as Java in 1995. bytecode, at Sun Microsystems, including Mike Sheridan and Patrick Naughton, but Gosling is widely credited as the primary creator and is often called the "father of Java."Sun Microsystems was later acquired by Oracle in 2010, which is why Oracle now owns and maintains Java.

It was created at Sun Microsystems by a team led by James Gosling and was first released in 1995. Java programs are compiled into bytecode, which runs on a Java Virtual Machine (JVM). This design supports Java's famous idea: “Write Once, Run Anywhere.”

Java is a programming language people use to build apps, websites, and software — like a set of instructions computers can understand. You write Java code once, then a compatible JVM helps it run on Windows, macOS, or Linux.

How Java Works

JDK, JRE, and JVM

These three parts work together when you create and run a Java program.

JDK

Java Development Kit

The complete toolkit used to write, compile, debug, and run Java programs.

  • Includes the compiler (javac)
  • Includes development tools
  • Contains the JRE
→
JRE

Java Runtime Environment

The environment that provides the libraries and components needed to run Java software.

  • Contains Java libraries
  • Provides runtime support
  • Contains the JVM
→
JVM

Java Virtual Machine

The engine that reads Java bytecode and executes it on the current device.

  • Runs Java bytecode
  • Manages memory
  • Enables platform independence
