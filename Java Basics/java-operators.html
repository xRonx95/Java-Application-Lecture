1. Operators, Operands, and Expressions

An operator is a symbol that performs an action. An operand is a value used by the operator. An expression is a combination that produces a result.

An expression10 and 5 are operands; + is the operator
int result = 10 + 5; // expression evaluates to 15

String concatenation

The plus sign joins strings. Evaluation proceeds from left to right unless parentheses change it.

ConcatenationWatch the order
System.out.println("Total: " + 5 + 3);   // Total: 53
System.out.println("Total: " + (5 + 3)); // Total: 8

3. Assignment Operators

The simple assignment operator = places the value on its right into the variable on its left. Compound operators calculate and assign in one step.

Short formEquivalent formEffect
x += 5x = x + 5Add and store
x -= 5x = x - 5Subtract and store
x *= 5x = x * 5Multiply and store
x /= 5x = x / 5Divide and store
x %= 5x = x % 5Store remainder
Do not confuse: = assigns a value, while == asks whether two primitive values are equal.

5. Logical Operators

OperatorNameTrue when…

Eligibility rulesBoolean expressions
boolean canEnroll = age >= 18 && hasRequirements;
boolean getsDiscount = isSenior || isStudent;

Short-circuit evaluation

With &&, Java stops when the first condition is false. With ||, it stops when the first condition is true. This can prevent unsafe work.

Safe checkAvoid NullPointerException
if (name != null && name.length() > 0) {
    System.out.println(name);
}

6. Unary and Increment Operators

Unary operators work with one operand. ++ adds one, -- subtracts one, unary - changes a number’s sign, and ! reverses a boolean.

Prefix vs postfixJava
int x = 5;
int a = ++x; // x becomes 6, then a receives 6

int y = 5;
int b = y++; // b receives 5, then y becomes 6

As a standalone statement, both x++; and ++x; simply add one. Avoid placing several increments in one expression because the result is harder to read.

7. The Ternary Operator

The ternary operator selects one of two values using the pattern condition ? valueIfTrue : valueIfFalse.

Short decisionJava
String result = grade >= 75 ? "Passed" : "Failed";
int larger = first > second ? first : second;
Use it well: The ternary operator is ideal for a short choice that returns a value. Use a normal if-else when each branch performs several actions.

8. Operator Precedence

Precedence decides which operator is evaluated first. Parentheses have the highest practical priority and make intent clearer.

  1. Parentheses: ( )
  2. Unary: !, ++, --, unary + -
  3. Multiplicative: * / %
  4. Additive: + -
  5. Comparison: < <= > >=
  6. Equality: == !=
  7. Logical AND: &&
  8. Logical OR: ||
  9. Ternary and assignment
PrecedenceParentheses improve clarity
int first = 2 + 3 * 4;    // 14
int second = (2 + 3) * 4; // 20

Quick check

1. What is 17 % 5?

2, because 17 divided by 5 leaves a remainder of 2.

2. What is the result of true && false?

false. AND is true only when both operands are true.

3. Why use parentheses even when you know precedence?

They make the intended order explicit and reduce mistakes for readers.
