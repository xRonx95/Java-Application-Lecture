1. Anatomy of a Java Program

Syntax is the set of rules that tells us how Java code must be written. Java is case-sensitive, so Main, main, and MAIN are different names.

HelloWorld.javaFirst program
// A simple Java program
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
PartPurpose
public class HelloWorldDeclares a class named HelloWorld. The filename must be HelloWorld.java.
{ }Braces group related statements into a block.
main(...)The entry point where the Java Virtual Machine starts the program.
String[] argsStores optional command-line arguments as an array of text.
System.out.println(...)Displays text, then moves the cursor to a new line.
How to explain it: A class is the container, main is the starting door, and statements are the instructions performed inside it.

2. Essential Syntax Rules

Semicolon ;

Ends most executable statements, such as declarations and method calls.

Braces { }

Mark the beginning and end of classes, methods, loops, and decisions.

Parentheses ( )

Hold method parameters or the condition of an if or loop.

Whitespace

Spaces and indentation improve readability but usually do not change behavior.

Keywords and identifiers

Keywords are reserved words with a special meaning, such as class, public, int, and if. An identifier is a name created by the programmer for a class, variable, or method.

  • An identifier may contain letters, digits, the underscore (_), and dollar sign ($).
  • It cannot begin with a digit or contain spaces.
  • It cannot be a Java keyword.
  • Use meaningful names such as studentCount, not unclear names such as x1.
Common mistake: Writing system.out.println fails because the correct class name is System with a capital S.

3. Comments

Comments document the purpose of code and are ignored by the compiler. They should explain why something is done rather than repeat obvious code.

4. Displaying Output

Java provides several ways to print values to the console.

OutputDemo.javaExpected output: Name: Ana · Score: 95
System.out.print("Name: ");      // stays on same line
System.out.println("Ana");     // ends the line
System.out.printf("Score: %d%n", 95); // formatted output

6. From Source Code to Output

  1. Write source code and save it as HelloWorld.java.
  2. Compile with javac HelloWorld.java.
  3. The compiler creates bytecode in HelloWorld.class.
  4. Run it with java HelloWorld.
  5. The Java Virtual Machine (JVM) executes the bytecode.
Why Java is portable: The same bytecode can run on any operating system that has a compatible JVM—often summarized as “write once, run anywhere.”

7. Understanding Errors

Compile-time error

Java cannot translate the source code, often because of a missing semicolon, wrong spelling, or mismatched brace.

Runtime error

The program compiles but fails while running, such as dividing an integer by zero.

Logic error

The program runs but produces the wrong answer because the instructions are incorrect.

Debugging

The process of locating, understanding, and correcting errors in a program.

Quick check

1. Why must the filename be HelloWorld.java?

Because the public class is named HelloWorld. A public class and its source filename must match exactly.

2. What method is the entry point of a Java application?

public static void main(String[] args).

3. What is the difference between print and println?

print keeps the cursor on the current line; println adds a line break afterward.
