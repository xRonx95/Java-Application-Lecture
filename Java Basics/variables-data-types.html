1. What Is a Variable?

A variable is a named storage location in memory. Its data type tells Java what kind of value it can store and which operations are allowed.

Declare, initialize, updateJava
int age;          // declaration
age = 18;        // assignment
double grade = 94.5; // declaration + initialization
age = 19;        // update: the old value is replaced

The general pattern is dataType variableName = value;. A local variable must receive a value before it is read.

Common mistake: int score = "90"; is invalid because "90" is text, not an integer.

Declaring several variables

Clear declarationsRecommended
int firstScore = 85;
int secondScore = 90;
int thirdScore = 95;

Java permits int a = 1, b = 2;, but one declaration per line is often easier to explain and maintain.

Primitive types store simple values directly. Pick a type based on the meaning and required range of the data.

Integer versus decimal division

Numeric behaviorOutput: 2 then 2.5
System.out.println(5 / 2);     // 2: both operands are integers
System.out.println(5.0 / 2);   // 2.5: one operand is a double

3. Reference Data Types

A reference variable points to an object rather than storing the complete object value directly. Examples include strings, arrays, classes, and interfaces.

ReferencesJava
String studentName = "Mika";
int[] scores = {88, 91, 95};
String message = null; // currently refers to no object

String basics

  • studentName.length() returns the number of characters.
  • studentName.toUpperCase() returns an uppercase copy.
  • Use name.equals("Mika") to compare String content—not ==.
  • Strings are immutable: methods return a new String instead of changing the original object.

4. Constants and Type Inference

A constant is a variable whose value cannot be reassigned. Use the final keyword and an uppercase name.

Constants and varJava 10+
final double PI = 3.14159;
final int MAX_ATTEMPTS = 3;

var city = "Manila"; // compiler infers String
var count = 12;      // compiler infers int

var is only for local variables and still uses static typing: after inference, count remains an int.

5. Type Conversion and Casting

Widening conversion

A smaller compatible type is converted to a larger type automatically because the conversion is normally safe.

Automatic conversionint → double
int items = 12;
double itemCount = items; // 12 becomes 12.0

Narrowing conversion

A larger type is manually converted to a smaller type. Information may be lost.

Explicit castdouble → int
double average = 92.75;
int wholeAverage = (int) average; // 92, decimal part removed

Converting text and numbers

Parsing and conversionJava
int age = Integer.parseInt("18");
double price = Double.parseDouble("49.95");
String scoreText = String.valueOf(100);

6. Variable Scope and Lifetime

Scope is the part of a program where a variable can be accessed. A variable declared inside a block exists only inside that block.

Block scopeJava
int total = 80; // available throughout the method

if (total >= 75) {
    String result = "Passed"; // only inside this block
    System.out.println(result);
}
// System.out.println(result); // compile-time error
How to explain it: Imagine each pair of braces as a room. A local variable created inside that room cannot be used after you leave it.

7. Reading User Input with Scanner

InputDemo.javaKeyboard input
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = input.nextLine();

        System.out.print("Enter your age: ");
        int age = input.nextInt();

        System.out.printf("Hello, %s! You are %d.%n", name, age);
        input.close();
    }
}
Scanner pitfall: After nextInt(), the newline remains in the input. If you next call nextLine(), add an extra nextLine() first to consume it.

Practice and Review

Activity: Student Information

Ask for a student’s name, age, section, and three grades. Store each value using an appropriate type. Calculate the average and print a formatted student summary. Add a constant named PASSING_GRADE.

Quick check

1. Which type should store 19.99?

double is the usual choice for a beginner example involving a decimal. Real financial systems generally use BigDecimal for exact money calculations.

2. What happens when 9.8 is cast to int?

The fractional part is discarded, producing 9; it is not rounded.

3. Why use final?

It prevents reassignment, communicates intent, and protects values that should remain constant.
