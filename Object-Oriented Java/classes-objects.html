01 · Overview

What will you learn?

Object-oriented programming, or OOP, organizes a program around objects. Each object combines state (what it knows) and behavior (what it can do). Classes describe the structure that those objects will follow.

Learning objectives

At the end of this lesson, you should be able to:

  • Differentiate a class from an object.
  • Identify fields, methods, and constructors in a Java class.
  • Create objects using the new keyword.
  • Use dot notation to access an object's members.
  • Explain access modifiers and basic encapsulation.
  • Compare static members with instance members.
  • Build a simple Java program using multiple objects.
💡
Easy way to explain it

A class is like a house plan. The plan describes the rooms and doors, but nobody can live inside the plan. Objects are the actual houses built from it. They share one design, but each house can have a different color, address, and owner.

04 · Structure

Anatomy of a Java class

A basic class may contain a class name, fields, a constructor, and methods.

Student.java JAVA 
// 1. Class declaration
public class Student {

    // 2. Fields: the object's state
    String name;
    int age;

    // 3. Constructor: prepares a new object
    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 4. Method: the object's behavior
    void study() {
        System.out.println(name + " is studying.");
    }
}
Class nameNames the new data type.
FieldsStore an object's information.
ConstructorSets up a new object.
MethodsDefine what an object can do.

06 · Object creation

Constructors and the new keyword

A constructor is a special block that runs when an object is created. Its name must be the same as the class, and it has no return type—not even void.

Default-style constructor

Student() {
    name = "Unknown";
    age = 0;
}

Creates an object with starting values chosen by the class.

Parameterized constructor

Student(String n, int a) {
    name = n;
    age = a;
}

Receives values so each object can start with different data.

2Instantiatenew Student(...)
3Assignana = object reference
Important: If you do not write any constructor, Java can provide a no-argument default constructor. Once you write your own constructor, Java no longer adds that automatic one.

07 · State and behavior

Fields, methods, and dot notation

Fields represent an object's state, while methods represent its behavior. Outside the class, accessible members are used with the dot operator (.).

Aa

State: fields

Values that describe an object at a particular moment.

  • name = "Ana"
  • age = 19
  • course = "BSIT"
( )

Behavior: methods

Actions an object can perform or operations it provides.

  • study()
  • introduce()
  • takeExam()
Using object members
Student ana = new Student("Ana", 19);

System.out.println(ana.name); // Read a field
ana.age = 20;              // Change a field
ana.study();                // Call a method

08 · Current object

Understanding the this keyword

The keyword this refers to the current object. It is commonly used when a parameter has the same name as a field.

Without clear names
Student(String name) {
    name = name; // Wrong result
}
Using this
Student(String name) {
    this.name = name; // Correct
}

Read this.name = name as: “Put the constructor's name value into the name field of this current object.”

11 · Memory concept

Objects, references, and null

An object variable normally holds a reference to an object, not the complete object itself. Two variables can therefore point to the same object.

Student first = new Student("Ana", 19); Student second = first; second.name = "Angela";

Watch out for null.

A variable set to null points to no object. Calling a method through it causes a NullPointerException.

12 · Flexible behavior

Method and constructor overloading

Overloading means using the same method or constructor name with different parameter lists. Java chooses the matching version from the arguments supplied.

Overloaded constructors and methods
Student() {
    this("Unknown", 0);
}

Student(String name, int age) {
    this.name = name;
    this.age = age;
}

void study() {
    System.out.println(name + " is studying.");
}

void study(int minutes) {
    System.out.println(name + " studies for " + minutes + " minutes.");
}
Remember: Changing only the return type does not create a valid overload. The parameters must differ in number, type, or order.

13 · Useful object methods

toString() and object equality

Every Java class ultimately receives useful behavior from Object. Beginners most often meet toString(), equals(), and hashCode().

🪪

toString()

Returns a readable text description of an object.

⚖️

equals()

Can compare whether two objects should be considered equal by content.

#️⃣

hashCode()

Produces a number used by collections such as HashSet and HashMap.

A readable Student object
@Override
public String toString() {
    return "Student{name='" + name + "', age=" + age + "}";
}

Student ana = new Student("Ana", 19);
System.out.println(ana); // Java calls ana.toString()
== and equals() are not automatically the same.

== checks whether two reference variables point to the same object. A properly overridden equals() can compare object content.

14 · Object life cycle

From creation to garbage collection

An object moves through a simple life cycle while the program runs.

Class → new Object() → Use object → No references → Garbage collection
Visual sequence

The garbage collector may reclaim memory after an object can no longer be reached.

  1. Define. The class tells Java what the object will contain.
  2. Create. new allocates memory and runs a constructor.
  3. Use. References allow the program to access the object.
  4. Disconnect. The object becomes eligible for collection when no live reference can reach it.
  5. Reclaim. Java automatically manages the memory; the exact collection time is not guaranteed.

15 · Guided example

Complete example: a bank account

This example combines private fields, a constructor, methods, validation, two objects, and dot notation.

BankAccount.java JAVA 
public class BankAccount {
    private String owner;
    private double balance;

    public BankAccount(String owner, double balance) {
        this.owner = owner;
        this.balance = balance;
    }

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
        }
    }

    public void displayAccount() {
        System.out.println(owner + ": ₱" + balance);
    }

    public static void main(String[] args) {
        BankAccount ana = new BankAccount("Ana", 1000);
        BankAccount ben = new BankAccount("Ben", 500);

        ana.deposit(250);
        ben.withdraw(100);

        ana.displayAccount();
        ben.displayAccount();
    }
}
PROGRAM OUTPUT Ana: ₱1250.0
Ben: ₱400.0
  1. The class is defined. BankAccount describes the fields and available actions.
  2. Two objects are created. ana and ben each receive separate data.
  3. Methods change state. Depositing affects Ana's balance; withdrawing affects Ben's balance.
  4. Each object keeps its own state. A change to one account does not automatically change the other.

16 · Troubleshooting

Common beginner mistakes

01

Forgetting new

Student ana; only declares a variable. It does not create a Student object.

02

Giving a constructor a return type

void Student() is a method, not a constructor. Remove void.

03

Accessing a private field directly

Use the class's public getter, setter, or behavior method instead.

04

Confusing a class name with a variable name

Student is a type; ana is a variable referring to an object.

05

Using an uninitialized or null reference

Make sure the variable points to an object before accessing its members.

18 · Check your understanding

Quick assessment

Answer each question before opening its answer.

1 What is the main difference between a class and an object?

Answer: A class is a blueprint or definition, while an object is an instance created from that class.

2 Which keyword is commonly used to create a Java object?

Answer: The new keyword.

3 What is the purpose of a constructor?

Answer: It initializes a new object when the object is created.

4 What does this.name = name; mean?

Answer: It assigns the parameter named name to the current object's name field.

5 Which member belongs to the class rather than to each object?

Answer: A member declared with static.

6 Why are fields often declared private?

Answer: To protect the object's internal state and control access through methods.

7 What makes two methods valid overloads?

Answer: They share a name but have different parameter lists by number, type, or order.

8 What does == compare when used with objects?

Answer: It checks whether two references point to the same object.

9 When can an object become eligible for garbage collection?

Answer: When it can no longer be reached through any live reference.

10 What is the purpose of toString()?

Answer: It returns a readable text representation of an object.

Key words to remember

A blueprint that defines fields and methods.
Object
A working instance created from a class.
Field
A variable that stores object or class data.
Method
A named block of behavior.
Constructor
A special block that initializes a new object.
Reference
A value that points to an object in memory.
Encapsulation
Protecting data and controlling how it changes.
Instance
Another word for an object created from a class.
Static
Belonging to the class and shared by its objects.
Overloading
One name with multiple parameter lists.
