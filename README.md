JAVA & APACHE NETBEANS TUTORIAL WEBSITE

Files:
- index.html: Main homepage
- header.html: Reusable website header
- css/header.css: Header and mobile navigation styles
- css/index.css: Homepage and responsive content styles
- js/header.js: Loads the separate header and controls interactions

HOW TO RUN
1. Keep the folders and files in their current structure.
2. Open the project using Apache NetBeans, VS Code Live Server, XAMPP, or another local web server.
3. Visit index.html through the local server.

Important: Because the header is stored in a separate HTML file and loaded with
JavaScript, some browsers block it when index.html is opened directly as a file.
Running it through a local web server fixes this.
