02 · Core Concepts

How Java Swing handles a button click

Swing follows an event-driven programming model. The program waits for an action, such as a click, then invokes the registered listener.

1

User Action

The user clicks a JButton using a mouse or activates it using the keyboard.

2

ActionEvent

Swing creates an ActionEvent containing information about the action.

3

ActionListener

The registered listener executes the code inside actionPerformed().

JButton

A Swing component that performs an action when the user activates it.

ActionListener

An interface used to receive action events from buttons and other components.

ActionEvent

An event object containing information about the action that occurred.

Important classroom note:

Example 1

Basic JButton with ActionListener

This example prints a message when the button is clicked.

  1. 1
    Create the button.

    Use new JButton("Click Me").

  2. 2
    Add the listener.

    Register an ActionListener.

  3. 3
    Handle the action.

    Place the response inside actionPerformed().

ButtonExample.java
JButton button = new JButton("Click Me");

button.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("Button clicked!");
    }
});

Count button clicks

A variable can store state between events and update after each click.

ClickCounter.java

JLabel label = new JLabel("Clicks: 0");

Example 4

Read the ActionEvent command

The event object can identify which action command was triggered.

  1. 1
    Receive the event.

    The lambda parameter e represents the ActionEvent.

  2. 2
    Get the command.

    Use e.getActionCommand().

  3. 3
    Use the value.

    Print or compare the command as needed.

ActionCommand.java
JButton saveButton = new JButton("Save");

saveButton.addActionListener(e -> {

04 · Common Event-Handling Styles

Three ways to write a button listener

These approaches are all valid. Choose the form that keeps the program readable and maintainable.

StyleExampleBest use
Anonymous classnew ActionListener() { ... }Useful when teaching the full listener structure.
Lambda expressione -> { ... }Concise and common for short actions.

06 · Knowledge Check

Review your understanding

Answer each question before opening the suggested response.

1. What is the purpose of an ActionListener?

It receives action events and executes code when a component such as a JButton is activated.

2. What method is required by ActionListener?

The actionPerformed(ActionEvent e) method.

3. What does e.getActionCommand() return?

It returns the action command associated with the event, commonly the button text unless another command was assigned.

4. Why are lambda expressions useful for button events?

They provide a shorter syntax for functional interfaces such as ActionListener.

5. Can a web browser directly execute a Swing JFrame?

No. Swing is a desktop Java GUI toolkit. The examples on this lesson page simulate the expected result; the actual Java code should be run in Java or Apache NetBeans.
