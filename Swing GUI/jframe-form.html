Topic 1

Understanding JFrame and Java Swing

Java Swing is a toolkit for creating graphical user interfaces for desktop applications. A JFrame is the main window that holds interface components such as labels, text fields, buttons, tables, and menus.

Key definition

JFrame is a top-level Swing container. It provides the window title, border, minimize and close controls, and a content area where components are placed.

ComponentPurposeExample Use
JLabelDisplays text or an image“Full Name” field label
JTextFieldAccepts one line of textName or email address
JComboBoxProvides a list of choicesGrade level selection
JButtonStarts an action when clickedSubmit or Clear
JPanelGroups related componentsForm fields or button row
JOptionPaneDisplays a dialog messageSuccess or error feedback

private void btnSubmitActionPerformed(java.awt.event.ActionEvent evt) {
    String name = txtName.getText().trim();
    String email = txtEmail.getText().trim();
    String grade = cmbGrade.getSelectedItem().toString();

    if (name.isEmpty() || email.isEmpty()) {
        JOptionPane.showMessageDialog(this,
            "Please complete all required fields.",
            "Incomplete Form",
            JOptionPane.WARNING_MESSAGE);
        return;
    }

    JOptionPane.showMessageDialog(this,
        "Registration saved for " + name + " (" + grade + ").",
        "Success", JOptionPane.INFORMATION_MESSAGE);
}

Topic 3 · Code reference

Complete JFrame Program

This version creates the same form entirely in Java code. It is useful for explaining how components, layouts, and listeners work behind the visual designer.

StudentForm.javaComplete example
import java.awt.*;
import javax.swing.*;

public class StudentForm extends JFrame {
    private final JTextField txtName = new JTextField(20);
    private final JTextField txtEmail = new JTextField(20);
    private final JComboBox<String> cmbGrade = new JComboBox<>(
        new String[] { "Select grade", "Grade 7", "Grade 8",
                       "Grade 9", "Grade 10", "Grade 11", "Grade 12" }
    );

    public StudentForm() {
        setTitle("Student Registration Form");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setSize(520, 340);
        setLocationRelativeTo(null);

        JPanel formPanel = new JPanel(new GridBagLayout());
        formPanel.setBorder(BorderFactory.createEmptyBorder(24, 28, 24, 28));
        GridBagConstraints gbc = new GridBagConstraints();
        gbc.insets = new Insets(8, 8, 8, 8);
        gbc.fill = GridBagConstraints.HORIZONTAL;

        addRow(formPanel, gbc, 0, "Full Name:", txtName);
        addRow(formPanel, gbc, 1, "Email:", txtEmail);
        addRow(formPanel, gbc, 2, "Grade Level:", cmbGrade);

        JButton btnClear = new JButton("Clear");
        JButton btnSubmit = new JButton("Submit");
        JPanel buttonPanel = new JPanel(new FlowLayout(FlowLayout.RIGHT));
        buttonPanel.add(btnClear);
        buttonPanel.add(btnSubmit);

        gbc.gridx = 0; gbc.gridy = 3; gbc.gridwidth = 2;
        formPanel.add(buttonPanel, gbc);

        btnSubmit.addActionListener(event -> submitForm());
        btnClear.addActionListener(event -> clearForm());
        add(formPanel);
    }

    private void addRow(JPanel panel, GridBagConstraints gbc,
                        int row, String label, JComponent input) {
        gbc.gridwidth = 1; gbc.gridx = 0; gbc.gridy = row;
        panel.add(new JLabel(label), gbc);
        gbc.gridx = 1; panel.add(input, gbc);
    }

    private void submitForm() {
        String name = txtName.getText().trim();
        String email = txtEmail.getText().trim();

        if (name.isEmpty() || email.isEmpty() || cmbGrade.getSelectedIndex() == 0) {
            JOptionPane.showMessageDialog(this,
                "Please complete all required fields.",
                "Incomplete Form", JOptionPane.WARNING_MESSAGE);
            return;
        }

        if (!email.matches("^[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+$")) {
            JOptionPane.showMessageDialog(this,
                "Please enter a valid email address.",
                "Invalid Email", JOptionPane.ERROR_MESSAGE);
            txtEmail.requestFocus();
            return;
        }

        JOptionPane.showMessageDialog(this,
            "Registration saved for " + name + ".",
            "Success", JOptionPane.INFORMATION_MESSAGE);
    }

    private void clearForm() {
        txtName.setText(""); txtEmail.setText("");
        cmbGrade.setSelectedIndex(0); txtName.requestFocus();
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new StudentForm().setVisible(true));
    }
}

Topic 4

Input Validation and User Feedback

A form should not simply collect information. It must also check whether the information is complete and reasonable.

1ReadGet field values
→
2CheckTest required fields
→
3DecideValid or invalid?
→
4RespondShow clear feedback

Good validation

  • Explains exactly what needs correction.
  • Keeps valid information already entered.
  • Returns focus to the problem field.
  • Uses a polite and specific message.

Avoid

  • Technical error messages students cannot understand.
  • Clearing the whole form after one error.
  • Accepting the default combo-box choice.
  • Showing success before checking every field.

Reference

Common Problems and Solutions

The JFrame does not appear.

Confirm that the main method calls setVisible(true) and that the correct class is being run.

The button does nothing.

Check that an action listener is connected to the correct button and method.

Components overlap or look misaligned.

Use a layout manager such as GridBagLayout. Avoid relying on fixed coordinates when possible.

The program closes immediately.

Use setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE) and look for errors in the IDE Output window.

A variable “cannot be resolved.”

Verify the component variable name, spelling, capitalization, and scope.
