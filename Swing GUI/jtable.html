Topic 04 • Core concept

What is a JTable?

A JTable is a Java Swing component used to present data in rows and columns. It is well suited for records such as students, products, attendance entries, employees, or transactions.

1

Your data

Names, courses, year levels, or other record values.

→
2

Table model

Stores column names, cell values, and row operations.

→
3

JTable view

Displays the model and lets the user select records.

Important distinction

The JTable displays the data, while the DefaultTableModel stores and changes the data. Updating the model automatically refreshes the table.

private void btnAddActionPerformed(java.awt.event.ActionEvent evt) {
    String id = txtStudentId.getText().trim();
    String name = txtName.getText().trim();
    String course = cmbCourse.getSelectedItem().toString();
    int year = (Integer) spnYear.getValue();

    if (id.isEmpty() || name.isEmpty()) {
        JOptionPane.showMessageDialog(this,
            "Student ID and complete name are required.",
            "Incomplete Information",
            JOptionPane.WARNING_MESSAGE);
        return;
    }

    DefaultTableModel model =
        (DefaultTableModel) tblStudents.getModel();
    model.addRow(new Object[]{id, name, course, year});

    clearForm();
    JOptionPane.showMessageDialog(this, "Record added successfully.");
}

Topic 11 • Update and delete operations

Select, update, and delete records

Load the selected row into the form

Table mouse-click event
private void tblStudentsMouseClicked(java.awt.event.MouseEvent evt) {
    int row = tblStudents.getSelectedRow();
    if (row == -1) return;

    int modelRow = tblStudents.convertRowIndexToModel(row);
    DefaultTableModel model =
        (DefaultTableModel) tblStudents.getModel();

    txtStudentId.setText(model.getValueAt(modelRow, 0).toString());
    txtName.setText(model.getValueAt(modelRow, 1).toString());
    cmbCourse.setSelectedItem(model.getValueAt(modelRow, 2).toString());
    spnYear.setValue(model.getValueAt(modelRow, 3));
}

Update the selected row

int viewRow = tblStudents.getSelectedRow();
if (viewRow == -1) {
    showSelectionWarning();
    return;
}

int row = tblStudents
    .convertRowIndexToModel(viewRow);
DefaultTableModel model =
    (DefaultTableModel) tblStudents.getModel();

model.setValueAt(txtStudentId.getText().trim(), row, 0);
model.setValueAt(txtName.getText().trim(), row, 1);
model.setValueAt(cmbCourse.getSelectedItem(), row, 2);
model.setValueAt(spnYear.getValue(), row, 3);

Delete the selected row

int viewRow = tblStudents.getSelectedRow();
if (viewRow == -1) {
    showSelectionWarning();
    return;
}

int answer = JOptionPane.showConfirmDialog(this,
    "Delete the selected record?",
    "Confirm Delete",
    JOptionPane.YES_NO_OPTION);

if (answer == JOptionPane.YES_OPTION) {
    int row = tblStudents
        .convertRowIndexToModel(viewRow);
    ((DefaultTableModel) tblStudents.getModel())
        .removeRow(row);
}
Why use convertRowIndexToModel()? After sorting or filtering, the visible row number may differ from the model row number. Converting the index prevents updating or deleting the wrong record.

Topic 13 • Reliability

Validate input and prevent common mistakes

Required

Unique

Reject duplicate IDs

Compare the new ID with every existing value in column 0.

Range

Limit the year level

Confirm

Protect deletion

Ask for confirmation before permanently removing a selected row.

Check for a duplicate student ID
private boolean idExists(String id, int ignoredRow) {
    DefaultTableModel model =
        (DefaultTableModel) tblStudents.getModel();

    for (int row = 0; row < model.getRowCount(); row++) {
        if (row == ignoredRow) continue;

        String savedId = model.getValueAt(row, 0).toString();
        if (savedId.equalsIgnoreCase(id)) {
            return true;
        }
    }
    return false;
}

Topic 14 • Complete runnable example

Student Records application

This code-only version can be copied into a new Java class named StudentTableApp. It demonstrates JTable without relying on generated GUI Builder code.

StudentTableApp.java
import java.awt.*;
import java.util.regex.Pattern;
import javax.swing.*;
import javax.swing.event.DocumentEvent;
import javax.swing.event.DocumentListener;
import javax.swing.table.DefaultTableModel;
import javax.swing.table.TableRowSorter;

public class StudentTableApp extends JFrame {
    private final JTextField txtId = new JTextField(12);
    private final JTextField txtName = new JTextField(18);
    private final JComboBox<String> cmbCourse = new JComboBox<>(
        new String[]{"BSIT", "BSCS", "BSIS"}
    );
    private final JSpinner spnYear = new JSpinner(
        new SpinnerNumberModel(1, 1, 4, 1)
    );
    private final JTextField txtSearch = new JTextField(20);

    private final DefaultTableModel model = new DefaultTableModel(
        new String[]{"Student ID", "Complete Name", "Course", "Year"}, 0
    ) {
        @Override
        public boolean isCellEditable(int row, int column) {
            return false;
        }
    };

    private final JTable table = new JTable(model);
    private final TableRowSorter<DefaultTableModel> sorter =
        new TableRowSorter<>(model);

    public StudentTableApp() {
        super("Student Records Management");
        buildInterface();
        registerEvents();

        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setMinimumSize(new Dimension(850, 520));
        pack();
        setLocationRelativeTo(null);
    }

    private void buildInterface() {
        JPanel root = new JPanel(new BorderLayout(16, 16));
        root.setBorder(BorderFactory.createEmptyBorder(20, 20, 20, 20));

        JLabel title = new JLabel("Student Records Management");
        title.setFont(title.getFont().deriveFont(Font.BOLD, 24f));
        root.add(title, BorderLayout.NORTH);

        JPanel form = new JPanel(new GridBagLayout());
        form.setBorder(BorderFactory.createTitledBorder("Student Information"));
        GridBagConstraints gbc = new GridBagConstraints();
        gbc.insets = new Insets(6, 6, 6, 6);
        gbc.fill = GridBagConstraints.HORIZONTAL;

        addField(form, gbc, 0, "Student ID", txtId);
        addField(form, gbc, 1, "Complete Name", txtName);
        addField(form, gbc, 2, "Course", cmbCourse);
        addField(form, gbc, 3, "Year Level", spnYear);

        JButton btnAdd = new JButton("Add");
        JButton btnUpdate = new JButton("Update");
        JButton btnDelete = new JButton("Delete");
        JButton btnClear = new JButton("Clear");

        JPanel actions = new JPanel(new GridLayout(2, 2, 8, 8));
        actions.add(btnAdd);
        actions.add(btnUpdate);
        actions.add(btnDelete);
        actions.add(btnClear);

        gbc.gridx = 0;
        gbc.gridy = 4;
        gbc.gridwidth = 2;
        form.add(actions, gbc);

        table.setRowHeight(28);
        table.setSelectionMode(ListSelectionModel.SINGLE_SELECTION);
        table.setAutoCreateRowSorter(false);
        table.setRowSorter(sorter);

        JPanel records = new JPanel(new BorderLayout(8, 8));
        records.setBorder(BorderFactory.createTitledBorder("Student Records"));
        records.add(txtSearch, BorderLayout.NORTH);
        records.add(new JScrollPane(table), BorderLayout.CENTER);

        JSplitPane split = new JSplitPane(
            JSplitPane.HORIZONTAL_SPLIT, form, records
        );
        split.setResizeWeight(0.32);
        split.setBorder(null);
        root.add(split, BorderLayout.CENTER);
        setContentPane(root);

        btnAdd.addActionListener(event -> addRecord());
        btnUpdate.addActionListener(event -> updateRecord());
        btnDelete.addActionListener(event -> deleteRecord());
        btnClear.addActionListener(event -> clearForm());
    }

    private void addField(
            JPanel form, GridBagConstraints gbc,
            int row, String label, JComponent field) {
        gbc.gridwidth = 1;
        gbc.gridx = 0;
        gbc.gridy = row;
        gbc.weightx = 0;
        form.add(new JLabel(label + ":"), gbc);

        gbc.gridx = 1;
        gbc.weightx = 1;
        form.add(field, gbc);
    }

    private void registerEvents() {
        table.getSelectionModel().addListSelectionListener(event -> {
            if (event.getValueIsAdjusting()) return;
            loadSelectedRecord();
        });

        txtSearch.getDocument().addDocumentListener(new DocumentListener() {
            public void insertUpdate(DocumentEvent e) { filterRecords(); }
            public void removeUpdate(DocumentEvent e) { filterRecords(); }
            public void changedUpdate(DocumentEvent e) { filterRecords(); }
        });
    }

    private boolean validInput(int ignoredRow) {
        String id = txtId.getText().trim();
        String name = txtName.getText().trim();

        if (id.isEmpty() || name.isEmpty()) {
            JOptionPane.showMessageDialog(this,
                "Student ID and complete name are required.",
                "Incomplete Information",
                JOptionPane.WARNING_MESSAGE);
            return false;
        }

        if (idExists(id, ignoredRow)) {
            JOptionPane.showMessageDialog(this,
                "The student ID already exists.",
                "Duplicate Student ID",
                JOptionPane.WARNING_MESSAGE);
            return false;
        }
        return true;
    }

    private boolean idExists(String id, int ignoredRow) {
        for (int row = 0; row < model.getRowCount(); row++) {
            if (row == ignoredRow) continue;
            if (model.getValueAt(row, 0).toString().equalsIgnoreCase(id)) {
                return true;
            }
        }
        return false;
    }

    private Object[] formValues() {
        return new Object[]{
            txtId.getText().trim(),
            txtName.getText().trim(),
            cmbCourse.getSelectedItem(),
            spnYear.getValue()
        };
    }

    private void addRecord() {
        if (!validInput(-1)) return;
        model.addRow(formValues());
        clearForm();
        showMessage("Record added successfully.");
    }

    private void updateRecord() {
        int viewRow = table.getSelectedRow();
        if (viewRow == -1) {
            showSelectionWarning();
            return;
        }

        int row = table.convertRowIndexToModel(viewRow);
        if (!validInput(row)) return;

        Object[] values = formValues();
        for (int column = 0; column < values.length; column++) {
            model.setValueAt(values[column], row, column);
        }
        clearForm();
        showMessage("Record updated successfully.");
    }

    private void deleteRecord() {
        int viewRow = table.getSelectedRow();
        if (viewRow == -1) {
            showSelectionWarning();
            return;
        }

        int answer = JOptionPane.showConfirmDialog(this,
            "Delete the selected record?",
            "Confirm Delete",
            JOptionPane.YES_NO_OPTION);

        if (answer == JOptionPane.YES_OPTION) {
            model.removeRow(table.convertRowIndexToModel(viewRow));
            clearForm();
            showMessage("Record deleted successfully.");
        }
    }

    private void loadSelectedRecord() {
        int viewRow = table.getSelectedRow();
        if (viewRow == -1) return;

        int row = table.convertRowIndexToModel(viewRow);
        txtId.setText(model.getValueAt(row, 0).toString());
        txtName.setText(model.getValueAt(row, 1).toString());
        cmbCourse.setSelectedItem(model.getValueAt(row, 2).toString());
        spnYear.setValue(model.getValueAt(row, 3));
    }

    private void filterRecords() {
        String text = txtSearch.getText().trim();
        sorter.setRowFilter(text.isEmpty()
            ? null
            : RowFilter.regexFilter("(?i)" + Pattern.quote(text)));
    }

    private void clearForm() {
        txtId.setText("");
        txtName.setText("");
        cmbCourse.setSelectedIndex(0);
        spnYear.setValue(1);
        table.clearSelection();
        txtId.requestFocus();
    }

    private void showSelectionWarning() {
        JOptionPane.showMessageDialog(this,
            "Select a record from the table first.",
            "No Record Selected",
            JOptionPane.WARNING_MESSAGE);
    }

    private void showMessage(String message) {
        JOptionPane.showMessageDialog(this, message);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() ->
            new StudentTableApp().setVisible(true)
        );
    }
}

Topic 17 • Check your understanding

Knowledge assessment

Ask students to answer before opening each explanation.

1. What is the primary purpose of a JTable?

It displays structured data in rows and columns and allows users to view or select records.

2. What is the role of DefaultTableModel?

It stores the JTable's column definitions and row data and provides methods for adding, updating, and deleting rows.

3. Why should JTable be placed inside JScrollPane?

The scroll pane displays the table header and allows users to reach rows or columns that do not fit in the visible area.

4. Which method adds a row to DefaultTableModel?

addRow(Object[] rowData) adds one row containing the supplied values.

5. What does getSelectedRow() return when no row is selected?

It returns -1, which should be checked before an update or delete operation.

6. Why is convertRowIndexToModel() important?

Sorting and filtering change view positions. The method converts the selected visible row to the correct underlying model row.

7. How can direct cell editing be prevented?

Override isCellEditable(int row, int column) in the model and return false.

8. What class is commonly used to filter JTable rows?

TableRowSorter works with RowFilter to filter and sort visible rows.

9. Does DefaultTableModel automatically save data permanently?

No. It stores data in memory. A file or database is needed for persistence after the program closes.

10. Give two examples of professional input validation.

Examples include rejecting blank required fields, preventing duplicate IDs, checking numeric ranges, and confirming destructive actions.
