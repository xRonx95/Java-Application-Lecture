01

Lesson overview

From static window to interactive form

A graphical form becomes useful when it can explain what information is needed, accept the user’s response, and perform an action. In Java Swing, labels, fields, and buttons provide these three essential functions.

◎

Learning competency

Design and program a Java Swing form that accepts, validates, and processes user input.

⌁

Prior knowledge

Java classes, variables, methods, data types, and the basic structure of a JFrame.

✓

Required output

A student profile form with meaningful labels, editable fields, and working Save and Clear buttons.

At the end of this module

Learning objectives

  1. Differentiate JLabel, JTextField, JPasswordField, JTextArea, and JButton.
  2. Set appropriate text, variable names, sizes, tool tips, and accessibility properties.
  3. Arrange form controls using a layout manager and consistent visual spacing.
  4. Read field values and respond to button-click events.
  5. Validate required input and provide clear feedback.
  6. Test and improve a form using a structured checklist.

03

Professional practice

Properties, names, and readable text

Every component has properties that control its appearance and behavior. Use clear visible text for users and meaningful variable names for programmers.

AVOID

Default or unclear names

jLabel1jTextField2jButton3

These names do not explain the component’s purpose.

→
USE

Purpose-based names

lblFullNametxtFullNamebtnSave

Prefixes identify the component; the rest identifies its role.

text

The words visible to the user, such as “Email Address” or “Save Profile.”

font

The typeface, style, and size. Use readable sizes and consistent weights.

foreground

The text color. Maintain strong contrast with the background.

enabled

Determines whether the component accepts interaction.

toolTipText

Provides a short helpful explanation when the pointer rests over a control.

mnemonic

Adds a keyboard shortcut, such as Alt + S for Save.

04

Interface design

Arrange controls as one visual system

Good layout reduces errors. Align labels, keep related controls together, use equal field widths, and place the primary action where it is easy to find.

01

Align

Keep labels and fields on a predictable grid.

02

Group

Place controls with related purposes close together.

03

Space

Use consistent gaps so every item is easy to scan.

04

Prioritize

Make the main action visually stronger than secondary actions.

Layout recommendation: Use GridBagLayout, GroupLayout, or nested panels. Fixed coordinates often break when fonts, window size, or operating systems change.

Code reference

Complete Working Program

This example builds the same form with Java code. It uses meaningful variable names, GridBagLayout, keyboard mnemonics, validation, and separate methods for each action.

StudentProfileForm.javaComplete example 
import java.awt.*;
import javax.swing.*;

public class StudentProfileForm extends JFrame {
    private final JTextField txtFullName = new JTextField(22);
    private final JTextField txtEmail = new JTextField(22);
    private final JTextField txtStudentNumber = new JTextField(22);

    public StudentProfileForm() {
        setTitle("Student Profile");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setSize(600, 400);
        setLocationRelativeTo(null);

        JLabel lblTitle = new JLabel("Student Profile");
        lblTitle.setFont(new Font("SansSerif", Font.BOLD, 24));

        JLabel lblFullName = new JLabel("Full Name:");
        JLabel lblEmail = new JLabel("Email Address:");
        JLabel lblStudentNumber = new JLabel("Student Number:");

        lblFullName.setLabelFor(txtFullName);
        lblEmail.setLabelFor(txtEmail);
        lblStudentNumber.setLabelFor(txtStudentNumber);

        txtFullName.setToolTipText("Enter the student's complete name");
        txtEmail.setToolTipText("Enter a valid email address");
        txtStudentNumber.setToolTipText("Enter the official student number");

        JButton btnClear = new JButton("Clear");
        JButton btnSave = new JButton("Save Profile");
        btnClear.setMnemonic('C');
        btnSave.setMnemonic('S');

        JPanel formPanel = new JPanel(new GridBagLayout());
        formPanel.setBorder(BorderFactory.createEmptyBorder(28, 32, 28, 32));
        GridBagConstraints gbc = new GridBagConstraints();
        gbc.insets = new Insets(9, 9, 9, 9);
        gbc.fill = GridBagConstraints.HORIZONTAL;

        gbc.gridx = 0; gbc.gridy = 0; gbc.gridwidth = 2;
        formPanel.add(lblTitle, gbc);
        gbc.gridwidth = 1;

        addRow(formPanel, gbc, 1, lblFullName, txtFullName);
        addRow(formPanel, gbc, 2, lblEmail, txtEmail);
        addRow(formPanel, gbc, 3, lblStudentNumber, txtStudentNumber);

        JPanel buttonPanel = new JPanel(new FlowLayout(FlowLayout.RIGHT, 10, 0));
        buttonPanel.add(btnClear);
        buttonPanel.add(btnSave);
        gbc.gridx = 0; gbc.gridy = 4; gbc.gridwidth = 2;
        formPanel.add(buttonPanel, gbc);

        btnSave.addActionListener(event -> saveProfile());
        btnClear.addActionListener(event -> clearFields());
        getRootPane().setDefaultButton(btnSave);

        add(formPanel);
    }

    private void addRow(JPanel panel, GridBagConstraints gbc, int row,
                        JLabel label, JTextField field) {
        gbc.gridwidth = 1; gbc.gridx = 0; gbc.gridy = row;
        gbc.weightx = 0;
        panel.add(label, gbc);
        gbc.gridx = 1; gbc.weightx = 1;
        panel.add(field, gbc);
    }

    private void saveProfile() {
        String name = txtFullName.getText().trim();
        String email = txtEmail.getText().trim();
        String studentNumber = txtStudentNumber.getText().trim();

        if (name.isEmpty()) {
            showWarning("Please enter the student's full name.", txtFullName);
            return;
        }
        if (email.isEmpty() || !email.matches("^[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+$")) {
            showWarning("Please enter a valid email address.", txtEmail);
            return;
        }
        if (studentNumber.isEmpty()) {
            showWarning("Please enter the student number.", txtStudentNumber);
            return;
        }

        JOptionPane.showMessageDialog(this,
            "Student profile saved for " + name + ".",
            "Profile Saved", JOptionPane.INFORMATION_MESSAGE);
    }

    private void showWarning(String message, JTextField field) {
        JOptionPane.showMessageDialog(this, message,
            "Incomplete Form", JOptionPane.WARNING_MESSAGE);
        field.requestFocus();
    }

    private void clearFields() {
        txtFullName.setText("");
        txtEmail.setText("");
        txtStudentNumber.setText("");
        txtFullName.requestFocus();
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() ->
            new StudentProfileForm().setVisible(true));
    }
}

Events and validation

Turn input into a useful response

An event listener waits for an interaction. When the user selects a button, the listener runs the connected code. Before saving, the program should validate the information.

Effective feedback

  • Names the field that needs attention.
  • Explains how to correct the problem.
  • Moves keyboard focus to that field.
  • Uses a polite, concise message.

Ineffective feedback

  • Uses vague text such as “Error!”
  • Clears valid information unnecessarily.
  • Shows success before validation.
  • Exposes technical exception details.
QUICK CHECK

Which message is more helpful?

A. “Invalid input.”    B. “Please enter a valid email address, such as name@example.com.”

Answer: B. It identifies the problem and gives the user a useful example.

Troubleshooting reference

Common problems and corrections

The button does nothing when selected.

Confirm that an ActionListener is connected to the correct button and that the event method contains the intended statements.

“Cannot find symbol” appears for a field name.

Check spelling, capitalization, and scope. txtFullName and txtFullname are different names in Java.

The fields are too small or become misaligned.

Use a layout manager and set an appropriate column count, such as new JTextField(22). Avoid fixed coordinates.

The form accepts spaces as valid information.

Call trim() before isEmpty() so whitespace is removed before validation.

Pressing Enter does not activate Save.

Set the default button with getRootPane().setDefaultButton(btnSave).

A label does not move focus to its field.

Associate them with lblFullName.setLabelFor(txtFullName) and configure a mnemonic if needed.
