Create Your First Java Project

Complete the steps in order. Compare your NetBeans window with each picture before moving to the next step.

1

Open Apache NetBeans

Double-click the Apache NetBeans icon. Wait until the Start Page appears.

2

Start a New Project

From the top menu, click File, then choose New Project.

3

Select Java Application

Choose Java with Ant, select Java Application, and click Next.

4

Name the Project

Enter MyFirstApp in Project Name. Keep Create Main Class checked, then click Finish.

5

Write the Java Code

Open Main.java under Source Packages and type the sample “Hello, Java!” program.

6

Run and Check the Output

Click the green Run Project triangle. Confirm that Hello, Java! appears below.

Student tip: If your screen looks different, check the step number, read the caption again, and make sure the previous step was completed before continuing.
